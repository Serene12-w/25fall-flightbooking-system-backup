# 转机航班功能快速使用指南

## 如何预订转机航班

### 步骤1: 登录系统
```
选择: 1 (Passenger Login)
输入护照号和姓名
```

### 步骤2: 搜索并预订
```
选择: 1 (Search and Book Flight)
输入: 出发地 (例如: CAN)
输入: 目的地 (例如: JFK)  
输入: 日期 (例如: 2025-11-15)
```

### 步骤3: 选择路线
如果没有直飞：
```
系统自动显示转机选项：
Route 1: CAN -> PEK -> JFK (2 segments)
Route 2: CAN -> PVG -> JFK (2 segments)
...

输入: 1 (选择路线1)
```

### 步骤4: 选择舱位
```
1. First Class
2. Business Class
3. Premium Economy
4. Economy Class

输入: 4 (经济舱)
```

### 步骤5: 完成预订
系统会显示：
- 订单号
- 联程航班标识
- 所有段的航班号
- 价格（含联程10%优惠和会员折扣）

### 步骤6: 付款
```
选择: 2 (Pay for Ticket)
选择订单
输入信用卡号
```

### 步骤7: 值机选座
```
选择: 3 (Check In)
选择订单

系统会依次为每一段航班选择座位：
Segment 1: CAN -> PEK
  输入座位号: 30A
Segment 2: PEK -> JFK
  输入座位号: 15C

完成！
```

## 关键特性

### 转机时间限制
- 最短: 90分钟
- 最长: 12小时

### 联程优惠
- 自动享受10%折扣
- 叠加会员折扣

### 最多转机
- 最多2次转机（3段航班）

## 注意事项

1. **联程票不可拆分**: 必须按顺序乘坐所有段
2. **统一舱位**: 所有段必须是同一舱位
3. **不可退款**: 付款后不可退款
4. **统一值机**: 一次性为所有段选座

## 示例场景

### 场景: 广州到纽约
```
没有直飞航班时：

选项1: CAN -> PEK -> JFK
  - 第1段: CZ327 (12:00 - 14:30)
  - 转机: 2小时30分钟
  - 第2段: CA981 (17:00 - 18:00)
  - 总距离: 12,850 km
  - 价格: $1,377 (经济舱，含折扣)

选项2: CAN -> PVG -> JFK  
  - 更多选项...
```
